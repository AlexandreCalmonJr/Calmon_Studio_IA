Linux AppImage

Pacote universal para distribuições Linux x64. Dê permissão de execução antes de abrir.

Baixar AppImage

Como executar no Ubuntu / Debian

chmod +x Calmon-Studio-*.AppImage
./Calmon-Studio-*.AppImage --no-sandbox

No Ubuntu 24.04+, o parâmetro --no-sandbox contorna a restrição padrão de user namespaces do AppArmor.

Primeiros passos em 2 minutos

1

Abra o Calmon Studio

Ao iniciar, clique em Criar conta pessoal para configurar seu usuário local no SQLite embarcado.

2

Escolha seu motor de IA

Cole uma chave de API em Modelos & Provedores (Gemini, OpenAI, Groq) ou conecte o Ollama 100% offline.

3

Opcional: persona Calmon IA

ollama pull llama3.2:3b
ollama create calmon-ia -f models/Modelfile.calmon-ia
